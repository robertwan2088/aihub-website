# AIHub 官网

AI驱动的科技公司官方网站

## 项目结构

```
├── index.html      # 前台官网
├── admin.html      # 后台管理
└── README.md       # 项目说明
```

## 页面说明

### 前台官网 (index.html)
- 首页 - Hero区、核心能力
- 产品展示 - AI项目案例
- 解决方案 - 行业解决方案
- 关于我们 - 公司介绍、团队
- 新闻动态 - 公司新闻
- 联系我们 - 咨询表单

### 后台管理 (admin.html)
- 数据概览 - 统计数据
- 产品管理 - CRUD操作
- 新闻管理 - 发布新闻
- 线索管理 - 客户线索
- 系统设置 - 基本配置

## 技术栈

- HTML5
- CSS3
- Vanilla JavaScript

## 本地运行

直接双击 `index.html` 或 `admin.html` 即可在浏览器中查看

## 部署

支持部署到任何静态服务器或CDN
